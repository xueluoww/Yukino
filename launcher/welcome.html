01 / REQUIREMENTS

项目要求

  • Windows 10 / 11 其余平台未做适配与测试。
  • Python 3.10 或更新 启动器会自动检测本机 Python 版本；缺失或版本过低时会直接给出提示。
  • 一枚 DeepSeek API Key 用于对话生成。请求由本机直连 DeepSeek，费用走你自己的账号。
  • 首次启动会创建 data 目录 位于程序目录下，用于存放存档与本地配置。请勿在运行中删除该目录。

02 / ABOUT

项目介绍

Yukino 0.9 是一个运行在本机的单人 AI 文字冒险程序。它不联网托管、不设账号系统， 剧本、美术与全部存档都放在你自己的机器上，对话由你填入的 DeepSeek 密钥驱动。

当前提供两种玩法：世界模式通过时间、地点、事件与私有目标驱动人物活动，你可以自由说话、行动、拒绝或绕路； 沙盒模式保留以自由叙述与人物对话为主的玩法。 预制故事线另有阶段目标与收束节点，不等同于世界模式。每个存档的经历、记忆与状态互相独立。

公共包附带剧本、原创占位图与部分生成空场景，不附带原作人物美术，请按README补图。内容为日常向的校园生活：白天上课、社团活动、放学后的对话与事件， 人物关系随相处时间变化。

已知限制，请在开始前了解：存档变长之后，生成会明显变慢；恋爱线推进节奏很慢，短期内不会出现明显变化； 白天的课程内容仍在补充完善，部分时段只有简短而过。本版本不承诺上述以外尚未实现的功能。

04 / IMAGE GENERATION

选择画面生成方式

已有图片始终可以使用。生图配置与文字密钥分开保存；登录、环境检测不代表已成功生成图片。设置改变后，请正常停止游戏再重新启动。

仅使用已有图片

不调用生图服务，适合先试玩或已经准备好素材的剧本。

Codex 原生生图

使用 Codex 的图片能力。可以单独检测登录、安装本包工具，再由你完成官方浏览器授权；不会修改全局模型配置。

尚未检测

自动配置需要 Node.js/npm，将固定版本工具安装到本包 runtime，不全局安装；若未装 Node.js，请先从 官方站点安装 LTS。账号是否支持生图与额度，仍以实际服务为准。

独立图片 API · 无需 Codex

连接你选择的 OpenAI 兼容图片服务或本机兼容服务。需要图片模型自己的配置和额度；DeepSeek 文本密钥不能代替图片密钥。

校验只读取模型列表，不试画。参考图任务使用 /images/edits；不会忽略参考图后偷偷改用文生图，也不会在超时后自动重复扣费。

可灵账号 · 独立授权入口

无需 Codex，通过可灵官方 MCP 服务与 OAuth 授权。此入口可安装连接器、检测账号和工具目录；自动绘图仍待实际工具协议验证，不会自动提交计费任务。

尚未连接；自动生图未启用

需要 Node.js/npm 和可灵账号。连接器沿用原插件的标准 OAuth 流程，不收集 Cookie 或让你粘贴 Token；可灵生成使用其自身额度。
