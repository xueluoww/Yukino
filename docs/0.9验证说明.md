# Yukino 0.9验证说明

日期：2026-10-12。范围：当前世界运行源码同步、独立启动器、生图方式配置、公开副本与技术文档；不迁移玩家旧档，不重启正在运行的个人游戏，不向模型发送玩家存档。

## 已验证

- 图片适配与配置24项通过：模型列表不计费、真实本地文件、参考图编辑、格式错误、接口绑定、超时不重复提交、下载失败只重试下载、固定版私有安装参数、假MCP只读工具发现等。
- 启动器原有33项通过：端口、并发、服务身份、其他资料库保护、只读自检、旧世界不自动覆盖、异常HTTP请求及密钥校验顺序。
- 本机Codex CLI 0.160.1已登录，app-server可初始化并读取本人账号；未试画，generation_verified仍为false。
- 本轮图片测试使用合成密钥和本机假服务，真实图片API调用为0。可灵真实授权、计费生成、透明背景画质与人物一致性未验证。

## 保留的未通过结果

既有完整回归399项中，2项未通过、1项跳过。两项涉及前轮地点硬判断改变后，旧断言仍要求“前往教室先澄清”或“走进教室应调用解析模型两次”。相关解析源码本轮未修改；当前已经增加确定性地点判定，因此需要重新评审旧用例的输入与预期，不能删掉失败称全通过。

既有全量测试还依赖开发环境的静态剧本资料，不能作为无需环境的公共回归命令。本轮独立的图片与启动器检查用隔离资料库。历史长对话、200轮与真人试玩报告只证明对应的当时版本，不能替代本轮图片供应商的真实试画。

## 发布边界

GitHub版只含程序、作者模板、原创占位图、已有生成空场景及带署名音乐，不含原游戏人物美术、个人API密钥、玩家存档、原始任务输入或私有回滚备份。本机带美术包的data保持原样；公开初始内容从模板重新导入。

配置改变需要正常停止再启动；不会自动杀已有服务。运行时仍为5.7.10-world-trial，公开版本按用户明确要求改为Yukino 0.9。技术报告在根目录 `技术报告.md`，不合并进README。
