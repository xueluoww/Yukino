# Yukino 0.9

一个可以导入剧本、自由说话与行动、回溯独立存档的本地 AI 视觉小说。**剧本**提供世界、人物、地点、物品和特殊玩法；**壳**负责时间、状态、权限、模型调用与游戏界面。

## 先读：与 Codex Skills 的关系

仍推荐使用 Codex 和项目内的 [sillytavern-roleplay Skill](skills/sillytavern-roleplay/SKILL.md) 创作、导入与维护内容。**Skill 是操作规范，不是每轮游戏都必须调用的模型后端。**

| 使用方式 | 所需环境 |
|---|---|
| 使用已有图片、查看图鉴、地图、回看与存档 | Python + 浏览器 |
| 自由对话、世界模式人物活动 | 本地 Python 服务 + 自己配置的 DeepSeek 文本服务 |
| 播放预制固定分镜 | 本地播放；进入自由阶段才需要文本服务 |
| Codex 原生生图 | 已安装、已登录且支持图片能力的 Codex CLI |
| 独立图片 API 生图 | 自己配置的兼容图片接口与图片密钥，**不需要 Codex** |
| 可灵账号入口 | 独立 OAuth 授权检测；**自动绘图尚未接入** |
| 创作剧本、导入卡片、登记图片 | 推荐使用 Skill；其他 agent 也可阅读 Markdown 并调用脚本 |

本项目公开版本现为 **Yukino 0.9**，内部运行时仍为 `5.7.10-world-trial`。版本名按用户明确要求更新，不代表旧存档自动迁移。

## 只想玩已有春物剧本，请先看这里（熟悉使用方法可跳过）

春物人物、个人与家庭背景、校园设定、自由开场及终卷时期的原创互动短篇已经附带。短篇含剧透，有预设方法、自由目标阶段与回溯；不是原著全文或官方游戏复刻。

**GitHub 公共包没有完整原作美术库。** 人物与普通场景使用原创姓名标签 SVG 占位图；它们不是正式头像、立绘或图片参考。另有两张此前用 Codex 制作的空场景 PNG，来源与提示词在 `skills/sillytavern-roleplay/assets/galgame/storyline-backgrounds/`。本机带美术测试包与这个公共包的美术内容不同，不能把个人包整体上传。

### 图片来源与补图

优先准备现有图片，再少量生成缺失状态。此前选用的参考库是 [broscolotos/oregairukan](https://github.com/broscolotos/oregairukan)，人物目录为 [usable/chara](https://github.com/broscolotos/oregairukan/tree/main/usable/chara)。它收录原游戏图像，是第三方移植项目，**不是官方免费素材授权站**；公开可下载不等于有开放重分发许可。

1. 选择人物、服装与表情一致的透明 PNG。文件编号不是情绪名；`miura` 对应三浦，`ebina` 对应海老名。不要为不同人物复用同一张脸，也不保证该库覆盖全部15人。
2. 将你准备的图片放入本项目 `data/browser/assets/`，按人物卡的真实 ID 合并登记 `data/browser/characters.json` 中的 `avatar`、`sprites`、`reference` 和服装。
3. 可让 Codex 使用项目 Skill 登记，明确 **资料库是这个项目的 data**，不要采用全局技能默认库。先列缺图，再少量补画；不要改写旧存档冻结的人设或剧情。
4. 刷新后核对图鉴、舞台、画廊和真实图片 URL。已有图的播放不调用生图服务。

完整目录对照、JSON 示例与导入请求见 [素材来源与导入](skills/sillytavern-roleplay/references/oregairu-art.md)。该文中的资料库示例路径在本公共包应替换为 `data/`。占位 SVG 不能作为真人物参考图或重画原图；需先补实际 PNG/JPEG/WebP。

音乐为5首 Kevin MacLeod 曲目，CC BY 4.0，署名和来源见 [CREDITS](skills/sillytavern-roleplay/assets/galgame/music/CREDITS.md)，不是原作音乐。代码的 AGPL 许可不覆盖原游戏图片。

## 启动

需要 Windows 10/11、Python 3.10+、浏览器和自己的 DeepSeek 配置。

1. 下载本仓库并完整解压，双击 **启动 Yukino0.9.bat**。
2. 首启页填写 DeepSeek API Key，点击“保存并校验”。校验失败不覆盖旧密钥。
3. 在独立的“画面生成方式”区域选择已有图、Codex或图片API；可灵另有授权检测入口。先试玩可保持仅已有图片。
4. 点击“启动游戏”，选择剧本、主角、新档模式与开场。

停止使用 **停止 Yukino0.9.bat**。它按本项目实际端口关闭匹配的服务；处理中先完成或取消本轮，不强杀其他服务。改生图方式后需正常停止再启动，不会偷偷重启已有游戏。

不使用批处理也可运行：

```powershell
python -B -X utf8 launcher/setup.py
python -B -X utf8 launch.py --check
python -B -X utf8 verify.py
```

原有预写演示可用 `python launch.py --demo` 打开，使用独立 `demo-data/`；演示并非真实模型试玩，不要用它的对白证明角色生成质量。

## 分开的生图选项

- **Codex：** 使用原生路由与独立生图目录。可只读复用桌面访问凭据，或“为Yukino单独登录”；不会刷新、改写桌面登录。“检测登录与连接”不生图，“试画一张（使用额度）”明确生成并检查图片，再选择启用。工具安装仍在本包runtime。
- **独立图片 API：** 配置带版本前缀的地址、真实图片模型和专用密钥。兼容的文生图走 `/images/generations`，参考图编辑走 `/images/edits`。读取模型列表仅验证连接，不证明图片质量。接口不支持参考图时，相关任务会停止说明，不能悄悄忽略。
- **可灵：** 可单独配置连接器、打开 OAuth 并检测账号和工具目录。参考插件已有可行连接方式，但本轮没有真实可灵账号验证，**没有启用自动计费生成**，不猜测工具参数。
- **已有图片：** 不调用生成服务。各方式不共用文本密钥、不静默切换供应商。

自动图片可能消耗相应服务额度。生成结果不明确时，不会自动重提相同任务；图片已生成但下载失败只重试下载。配置改变不会改写故事事实或覆盖旧图版本。

## 玩法与这次更新

**沙盒模式**保留自由叙述；**世界模式**由基础动作、时间、私有目标、日程与事件驱动人物生活。玩家只决定自己的言行；人物可以拒绝。两种模式在新档选择并冻结，不中途迁移旧档。

世界模式提供地图、课表、关系、独立心声与事件入口；事件分主角、世界和公共预期排期。固定活动不强迫主角或所有NPC参加，人物意向与实际到场分别结算。

本轮同步当前世界、日常、关系、地图、校历及模型协议修复，并加入独立启动器与图片后端。新增图片检查24项、启动器检查33项通过；既有399项完整回归有2项旧地点断言未通过、1项跳过，结果保留。Codex登录与握手已实测，真实供应商图片质量和可灵生成尚未验证。详情见 [0.9验证说明](docs/0.9验证说明.md)。

## 数据与安全更新

个人存档、分支快照、任务和素材在 `data/`；本包默认不写全局 Codex 资料库。密钥以 Windows DPAPI 加密，绑定当前用户。复制到别的机器后通常需重新填写密钥。

**不要用新包的 data 覆盖自己的旧 data，不要对已游玩的目录运行旧构建脚本的 --clean。** 更新前正常停止并备份整个资料库，只替换程序文件。只复制存档 JSON 不足以迁移动态图片；不要手工删分支快照清空间。优先使用游戏内管理、回收、恢复与导出。

项目新模板和校历只影响按新模板建立的新档；旧档继续使用冻结的剧本与状态。文字与生图请求会发送对应上下文或参考图到你选择的服务，不是完全离线运行。
