# 人物日程接口（世界模式可选功能）

壳维护日程状态、执行链、时间、权限与请求预算；运行卡不要求剧本作者编写。剧本只需可选的地点绑定和特殊日程内容。随地图评审修复安装到正式 skills；只有带显式功能开关的新世界档启用，旧档不迁移。地图配置见 [地点探索](location-exploration.md)。

## 可选作者配置

作者每人最多8项、模型最多4项。校历、公开活动与实际承诺合成的运行日程卡另限16项；可选活动不能挤掉既有课程、承诺与返家。公开活动的本人参加判断和邀请承接详见 [固定事件制作](calendar-authoring.md)。

在 `world.features` 添加 `npc_schedule_v1`，并选择以下配置。必须是世界模式新档；沙盒和无开关旧档不启用。

```json
{
  "version": 1,
  "generation": "shell",
  "actors": {
    "lin": [
      {
        "id": "afternoon-rest", "location_id": "club",
        "window_start": 975, "window_end": 990, "duration": 5,
        "purpose": "在活动室稍作休息", "activity_kind": "rest",
        "strength": "routine", "flexibility": 10, "weekdays": [0,1,2,3,4]
      }
    ]
  }
}
```

该对象放在 `world.schedules`，人物与地点 ID 必须真实存在。字段单位均为故事分钟：975 是 16:15；`weekdays` 0=周一、6=周日；有校历且无确定日期时也可用校历星期；`day` 可指定从开局起第几天。最多每人 8 项，窗口 0–1439、持续 1–180 分钟、弹性 0–120 分钟。可选 `timing:"arrival"`（默认，先扣实际路程准备到场）或 `timing:"departure"`（出发窗口，不要求提前到家）。持续时间是实际到场后的活动，不是完成时刻。壳默认返家采用17:30–18:30出发窗口，教室准备与带时刻约定保持到达窗口；不是原著社团统一散场时间。正在交流的普通安排仍允许短延期。

| 选项 | 行为 |
|---|---|
| `generation: shell` | 对未写安排的人物，仅利用明确的本人 classroom_id/home_id 生成稀疏默认；不猜考试、工作或社团 |
| `generation: none` | 未写的人物没有新增日程；原目标系统仍可运行 |
| `generation: model` | 懒构建时用本人权限视野提议普通安排；每天最多一条请求，异常退回壳规则 |
| `actors.lin: []` | 作者明确让该人物没有安排，覆盖壳/模型生成 |
| `strength: routine` | 普通意愿，可在交流冲突时短延期 |
| `strength: commitment` | 作者规定或实际说出的约定，优先于普通安排 |
| `strength: critical` | 作者明确的强约束，不允许模型无依据延期；仍审查物理条件、时间和实际执行容量 |

生成模型只能提出 routine，地点来自本人的已知地图。它不决定别人的目标、不改权威状态、不把计划当参与记录。壳当前默认只有教室准备和回家休息，不能视为已经有原著全天日程。

### 上课日与固定下课时刻

作者可在普通安排里设置 `school_days_only:true`，只在冻结校历判定为上课的当天生成。必须配置校历，且只能由作者声明；模型不能自行增加此限制。它尊重周末、祝日、假期与 `special_days` 的补课/免课覆盖，不等同于简单的周一至周五。显式配置某个人的 `actors` 会替代其壳默认普通日程，仍想保留返家就必须同时列出返家安排；课程由校历继续合成。

壳合成的课程到达窗口采用整段 `period.start`–`period.end`，持续时间仍为该课完整时长。课程以固定下课时刻为截止，晚到只占用剩余时间，不能从晚到时刻重新上满一节课；恰到下课时不追认参加。运行条目中的 `calendar_period` 是壳依据冻结校历附加的内部标识，作者和模型不能在输入中伪造它。一般 stay/rest 活动仍按实际到场后的 `duration` 结算。

春物模板 revision 16 为雪乃补充上课日15:30–17:00可到场的侍奉部普通安排，实际停留20分钟，同时保留17:30–18:30的返家出发窗口。具体钟点是本游戏的模拟安排，不声称为原著明确作息；交流、受阻和真实路线仍由原日程状态机处理，不保证她在任意时刻一定在活动室。阅读目标保留，停留完成不等于已经读书。重新导入模板并新建世界模式档才采用作者新安排；旧档冻结配置不无声迁移。

本次考勤审计修复按用户要求未运行测试或模型验证，文件同步核对不代表玩法已通过复测。

## 执行标准

日程状态为 planned/delayed/blocked/travelling/occupying/completed/missed/cancelled。按 critical→commitment→routine 排序，但共享原有目标容量，不会为了强约束瞬移、盗取物品或越过门锁。

到开始边界时，壳检查路线、人物存活、当前占用、门/入口、可开始窗口，再通过原有目标→行动计划→逐段移动→到达→实际占用结算。到达只完成“到访目标”，不等于整项日程完成；stay/rest 达到真实持续时长后才完成。只有物理受阻才写对应 blocked 原因；模型预算耗尽采用程序优先级，不冒充物理障碍。

模型冲突决策仅在近两分钟有交流等条件下调用，每人物每天最多一次，可延期普通日程至多 30 分钟；额度包含格式修复和实际传输重试。平静且无生成需求时零新增请求。预算卡随存档事务提交，事务整体回滚后的后续请求计费不能仅凭此卡追踪，实际请求日志仍须保留。

日程目前只支持 stay/rest，**不能把读书、借书、交接、考试成功等设成直接完成效果**。阅读和物品行为仍需原来的许可及动作环节。不同人物并发活动不重复增加世界总时间，玩家每次行为的时间推进仍是唯一公共时钟。

## 语言、约定与隐私

复用现有语言动作检测器：人物实际说出、经审查的带时间移动承诺，才生成约定关联；取消只改本人的相关安排与目标。不是第二个自由造卡解析器。未来日期承诺留在有来源的 plan 中，进入那天才构建必要条目。

当天卡默认只有本人可见。回复视野不塞完整私人日程，旁白不泄露远处计划。游戏地图中的“已知约定”只投影实际听到、有事件来源的表达，展示对方说过的话，不代表玩家已答应，更不保证对方实际已赴约。世界事件可记录实际行动；技术预算与日程结算日志不作为玩家人物事件。

## 跨日与回溯

每人使用固定 `schedule:<actor>` 卡，历史实际结果留在不可变事件包。单次长等待最多构建起始日与终点日，跳过的中间日用 simulation_gap 标记，不补写完成人物活动。跨午夜仍未结束的真实占用可保留到实际结束，未来约定按来源继承。

加载/投影检查 actual_* 与 completed_at，不能出现故事时刻之后的“实际完成”。异常卡从人物视野隔离，权威执行要求显式恢复，不能无声改写旧档。回溯到较早的快照只继承当时的计划与实际，不带兄弟分支或父分支更晚结果。

本轮没有跳日按钮、强制玩家日程或完整考试/工作模拟。采用范围与测试缺口须看本轮报告，不能把离线执行通过当作全天自由游玩已全部验证。
