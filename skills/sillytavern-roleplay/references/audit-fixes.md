# 审计及试玩修复：维护约定

公开名称仍为 Yukino 0.8。这是当前世界模式运行补丁，不改变沙盒/世界模式边界。

第二轮补丁增加导入时的家/主角地点默认值保留、翻页与坐起动作、门内应答的旁白核对，以及轻量 `/api/progress` 轮询。人物个人资料的来源、开篇范围及未知项见 [春物个人背景](oregairu-personal-background.md)。家庭资料对新档生效，不改旧档冻结人设。

## 保存、删除与恢复

- `storage_codec.py` 在磁盘 JSON 的 `turns[*].world_packet.state_after` 使用 `$yukino_state_zlib_v1`（zlib + base64）无损压缩。内存、模型输入、世界哈希依然使用普通对象。旧普通 JSON 可以继续读取；外部工具读取新磁盘档应调用 `storage_codec.loads` 或 `tavern.load_json`，不能把压缩标记当世界状态。它不压缩模型上下文。
- `tavern.atomic_json` 写紧凑 JSON；不批量重写历史档。回溯、导入、回看通过统一读取器解码。存档包继续验证完整世界链。
- 新回溯文件另有 `$yukino_checkpoint_zlib_v1`，压缩完整独立快照，不依赖相邻文件或后续存档。`storage_codec.loads` 同时解码新旧格式；图片引用检查也必须读解码后的快照，不能搜索压缩字面文本。旧回溯文件不批量转换。完整历史仍重复保存，总量不是线性增量存储。
- `SaveManager.delete` 将存档、回溯、记忆及该档的 jobs 回收；只有不被其他存档、回溯或公共图库引用的图片目录随档回收。公共素材有独立生命周期，删除一个档不等于删除公共素材。
- `purge` 是显式的彻底清除入口，连旧删除实现留下的该档 jobs 也清除；保留仍被引用的图片。回收站确认后调用，不自动清空旧回收记录。
- `restore` 先检查冲突，在移动前后记录进度，可接续进程中断的恢复。路径中两份同时存在时保留两份并拒绝覆盖。
- `.write.lock` 只有内容是 PID、足够旧且该进程确认已死才自动移除。活进程锁、权限不明及无 PID 的锁不抢占。
- `job_retention.retain` 清除完成请求的提示词等私有中间文件，旧请求仅保留最近 8 份恢复/诊断材料。权威对白仍在存档里；失败请求的必要材料会暂留。

## 时间与取消

`runtime_budget.WorkBudget` 是壳的工作量上限，剧本不能提高它。一个世界回应共享 180 秒期限、1,024 次推进边界、64 次模块调用及 64 次模型请求；模型校验重试也计入。单次时间输入/API1 时间效果限整数 0–10,080 分钟。正常跨日不因旧的 128 边界阈值被误拒。

超预算或取消抛出 `BudgetExceeded`，不允许被普通动作失败的 `ValueError` 降级吞掉，提交前再检查。取消不会中断已进入保存阶段的提交；正在进行的网络请求需返回或超时后结束。世界模式菜单可取消本轮；两种模式都可关闭服务。长等待超过人物规划额度时仍记录 `simulation_gap`，不能宣称整段都完整模拟。

## 许可与主角权限

- `permission_language.py` 区分肯定许可、问句、前置条件与后续保管限制。“可以现场看，但不能带走”允许读，不允许取走。授权绑定当前对话实际请求/明确提供的物品，不能把书架请求授权到角色自己的笔记。
- `card_runtime` 在玩家说出许可后也调用 `from_speech`；NPC 借阅计划允许向玩家提问，但不生成玩家同意。阅读仍检查所有者、同场、数量、期限和撤销。
- `action_guard` 不因普通“观察能力”解锁 NPC 控制，拒绝泛称、别名、插入代词的直接行动指定。特殊能力需冻结的静态来源及执行接口；有设定不等于凭空执行任意结果。

## 物品、在场、地点与可见活动

- 新档初始化不能静默丢掉作者明确声明的初始物品。旧格式的命名初始物品转换为定义；旧随身笔记本兼容读写规则。无名称且无定义的对象明确报错。不从背景图造出所有家具、书籍或车辆。
- 未指定地点的人物保持未入镜，不聚集在默认走廊。大区域的“同地点”与“实际接触”分开；明确环顾可建立少量近处接触，小房间同场人物可见。大区域未接触的离开也不通知玩家。
- 门有权威 `open/locked` 状态。敲门建立短暂的门两侧听闻范围，可以有门内答话，但不会把门内立绘放在门外。移动按路径并重置站姿，零分钟移动同样有到场记录。
- 重要地点澄清保存为 `pending_input`；内心和普通说话不自动取消。依赖未完成移动的座位/抽屉行为暂停；可以明确取消或说明新行动。同一输入“我说的是自己的教室，前往那间教室”保留前半句对后半句的指代。
- 玩家语言只有明确“我现在/这就/马上…”才自动执行下一步行动。普通“我先回去”保留为打算，不无声移动。
- `world_observations.py` 从已执行的 NPC 阅读/写字/进食派生可见活动，只描述外在动作，隐藏内容、目标和动机。实际到场继续使用既有到场记录；目标结算、奖励、校验不出现在事件页。
- 旁白校验不存在的持有物、旧坐姿、门状态及逐字重复；失败后降级为真实可见事件描述，不伪造完成。人物可以沉默，不用强制台词解决重复问题。
