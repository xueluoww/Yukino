# 调整与重新生成画面（5.6）

在游戏设置中选择“调整当前画面”，或在画廊中打开一幅图后选择“调整这幅画面”。填写补充画面要求，等待新旧对照，再点击“采用新版”。需要启用画面生成和可用的 Codex 原生生图服务；演示模式及 SVG 示意素材不支持重新绘制。

原图在等待期间继续显示，新版以独立图片保存。没有采用的新版不进入公共图库。采用只绑定当前存档，不改故事时间、关系或物品；历史节点、其他存档保留原图。已经走过对应情节时，采用只加入当前画廊，不突然替换正在阅读的场景。背景与CG作为公共图库的独立备选版本，立绘保留人物和分支归属。画面描述不改变故事事实，生成结果仍需玩家目视确认。

接口均使用已有本地 Origin 和会话令牌保护：

- `POST /api/images/adjust`：`session_id, source_key, prompt, request_id`。来源必须是当前存档可查看的素材，提示词1–1200字；同编号同内容幂等，不同内容拒绝；当前档至多一项主动重画任务。
- `POST /api/images/adopt`：`session_id, key`。只接受本档已成功完成的新版。
- `POST /api/images/retry-adjustment`：`session_id, key`。只重试失败的新版，保留版本编号。

`browser/image-adjustments.json`记录请求、原图和采用状态；`facts.browser_image_choices`记录当前分支的选择。禁止覆盖原文件、修改旧节点或把兄弟分支的待选结果显示到当前存档。重新生成不复用旧图命中结果，原图作为首张参考，并保留原人物约束。
