# 世界模式回应建议（内部 5.7.5，公开名仍 Yukino 0.8）

世界模式每次完成回合后，由 `scripts/world_choices.py` 以主角权限裁剪的当前视图和本轮同场公开对白/旁白生成 0–3 个建议。人物心声、私有目标和远处事件不作为建议输入。

建议只写入该分支的 `browser_story.choices`，并用 `browser_choice_state.turn_id` 绑定对应回合。建议本身不结算动作、不写事件卡；点击仍只填入输入框，发送时走正常主体、能力、地点和物品审查。可以忽略建议自由输入。

本阶段新增一个可选建议请求，上限 380 输出 tokens；不为了生成建议重复整套人物管线。建议请求的格式、网络或权限检查失败时清空本轮建议，保留已生成对白和已确认动作，不沿用开场/前轮选项。诊断仅保留内部元数据，不出现在玩家事件页。已有旧世界档无回合标记的推荐在开场以后只读隐藏；下一轮成功生成后恢复。

沙盒原有主回复里的 `story.choices` 和预制线作者定义的选项不受此机制替换。当前不能宣称建议已被语义硬检查覆盖所有自由文本：实际执行仍必须通过发送管线。

本次同时补装此前漏掉的 `world_heartbeat.py` 到场观察检查；验证安装时比较整个运行源码集合，不只检查人工列出的补丁清单。实验测试文件另存，不随正式补丁部署。
