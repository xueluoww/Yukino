# 世界模式：个人记忆与模型运行协议

公开版本为 Yukino 0.8，内部运行时 5.7.10。沙盒继续使用原来的引擎；旧实验的全局分层摘要没有启用。

## 四个部分

1. 当前场景：人物静态资料、权威时间、位置、可见人物、真实物品和短对话。
2. 个人笔记：每人一张 `personal_memory` 卡，最近 12 条听闻、48 条关键摘录；每 16 条形成一份带原文来源的章节摘录，最多保留 8 份索引。摘录不让模型重新推算状态。
3. 按需检索：按当前问题的中文字词片段、名称与精确编号匹配本人听过的历史，选取最近内容和相关旧内容，记忆注入最多 8,000 UTF-8 字节。不是 8,000 tokens，也不是向量数据库。
4. 冷归档：当前存档已有 `world_packet.records` 保存原文；不再复制一份全局文本库。检索只读当前分支传入的已提交前缀，检查真实听众和故事时间。缓存条目须有前缀或本轮事件证明。

来源包含说话人、实际听众、事件 ID、回合 ID、故事时间、原文。听到“预算是3200”只证明对方说过这个数；说“笔记本交给你”不证明物品已经交接。角色内心、其他人物的私有目标、导演旁白和异地对话不进入听闻记忆。已向某人透露的内容不能自动变成所有人的知识。未知姓名不因好感或主角设定自动公开。

旧世界存档继续游玩时会从其已有回合包找回实际听过的语言，新笔记随后续回合创建；安装不会批量改写旧存档或过去对白。缺少实际来源的旧猜测不能凭摘要恢复成事实。

## 协议与失败

`model_protocol.py` 为阶段提供最小结构约束，实际参数、原文证据、权限与事实检查仍由阶段校验器负责。现有 DeepSeek JSON-object 模式保留；没有宣称服务支持所有严格 JSON Schema 功能。

代码块包装、已知审核包装、表情展示值可做无损或展示层修正。编号、权限、物品、行动结果不能靠格式修复补造。每阶段最多两次尝试；传输错误沿用既有有界策略，权限/事实错误返回当前阶段的分类反馈。上下文超过预算不通过再次调用模型解决。

模型消息的指令与数据合计预算为 52,000 UTF-8 字节；优先去掉重复知识内容和低优先级检索摘录，不删除时间、人物权限和硬规则。必需场景本身超过预算时明确失败，需要收小场景。此上限不等于已经压缩磁盘存档，完整快照的历史体积问题仍存在。

执行结果逐步反馈：通过、拒绝、待确认或出错。前一步未拿到物品，后一步不能把它交出去；已成功的一步不因后一步失败而重演。失败反馈单独显示，故事事件页仍只展示人物活动。

普通身体动作和未提供具体台词的问候可以作示意结算，不编造主角具体台词。真正的发言原文走语言通道；包含未确定对象、条件、能力或角色控制的输入继续审查/澄清。

## 本轮检索与缓存修复

“部费/经费/预算/资金”等有限话题同义词参与检索，回答优先带入最多三条相关、非问句的原始听闻。`recall_focus` 保留事件来源和未核实性质，且计入同一个 8,000 字节记忆预算。人物生成与事实审查使用同一问题对应的视图和来源账本；问句不排挤旧陈述，玩家打算不变成双方约定。窄范围的数值/编号/姓名失忆检查会触发阶段内修复，不代替模型回答，不强迫人物透露信息。

世界模式文本请求在现有预算裁剪后使用 `prompt_cache.text_context` 递归排序：静态人设及较稳定规则在前，时钟、当轮输入、观察、对话和检索结果在后。状态卡是按 ID 查找的集合，可按模板/ID 排序；步骤、历史、对话顺序保持不变。所有原有字段和值保留，不冻结动态关系/知识，不合并不同角色视图。通用指令前缀加在各阶段规则之前，阶段协议及权限仍以本阶段为准。沙盒文本及生图接口未改。

本轮六组相同合成场景对照中，去掉首次请求后的输入缓存命中率由 29.79% 提升为 47.78%，未命中输入减少 25.81%。这是该人物组件样本的结果，不代表所有游戏调用、繁忙场景或总费用同比变化；服务端缓存可用性不是本地可保证的。原始 usage、内容等价校验与失败记录见 `work/yukino-cache-bugfix-20261011/修复与验证报告.md`。

澄清时只允许先执行没有条件、无需对象解析的独立普通手势前段；NPC 控制、能力拒绝和依赖条件不例外。待确认卡记录已成功的 `completed_prefix`，补全时不得重复执行。相同回合重复的失败文案只展示一次，原始失败记录仍逐条保留。

## 参考的工程方法

- [Anthropic：上下文工程](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：按需加载、结构化笔记与压缩；这里增加角色听众、分支前缀、故事时间与来源过滤。
- [LangGraph：错误处理](https://docs.langchain.com/oss/python/langgraph/thinking-in-langgraph)：区分可重试、模型可修复和需澄清的错误；这里重试范围限制为当前阶段。
- [PydanticAI：输出校验](https://pydantic.dev/docs/ai/core-concepts/output/)：结构与语义分开校验；这里用已有 Python 校验器实现，没有新增框架依赖。

这些是方法参考，不代表安装了相应框架，也不保证模型永不出错。运行证据与具体限制见项目工作区 `work/yukino-agent-memory-fix-20261011/修复与实验报告.md`。
