# 当前存档的故事文本导出

“回看”“脉络”弹窗与右上角“心声”窗口都有导出入口。导出文本为带 UTF-8 BOM 的 TXT（便于 Windows 记事本打开中文），也可下载 Markdown；完整故事将回看、脉络和人物心声作为分开章节合并。回看界面最近在前，文档按故事发生顺序排列。文档包含剧本名、存档 ID、分支名称与玩家称呼，避免混淆周目。心声只在明确导出心声或完整故事时加入独立附录。

本地只读接口：GET /api/export?session_id=<明确ID>&scope=story&format=txt。scope 为 story（回看）、plot（脉络）、thoughts（心声）、all（完整故事）；format 为 txt 或 md。未指定 ID 使用当前内存故事，指定已保存 ID 则读取该档；非法 ID、类型或不存在的存档拒绝。可在任意调用本技能的 Codex 窗口请求导出，先确认剧本/分支与 ID，再调用这个接口；无需恢复或激活该存档，也不读取其他存档的经历。

导出仅包含已记录内容，不调用文本或图片模型、不保存新轮次、不改变好感、记忆或回溯树。旧多人回看从本分支快照恢复真实分镜署名，完整核对对应时点的对白前缀；缺失记录保留为“历史文本”，不猜人物或补写对白。导出请求无额外生成费用。
