# Yukino 0.5 分层记忆长对话实验报告

结论：**本轮不列装新版分层记忆，原存档记忆系统保留。** 新方案显著减少输入量，但出现人物权限泄漏，不能以节约文本换取人物认知错误。

## 方法与边界

使用三个完全原创的隔离故事：书店义卖、旧报刊整理、社区读书会。每组含120轮模型实际生成的对话，共360轮；分批续写，轮数不足时补齐。再在固定回合加入可核验的代码、钥匙交接、约定、传闻纠正、拒绝和物品归还，防止两种方案面对不同真值。部分关键信息位于长回复末尾，检验截取片段是否遗漏细节。没有读取或发送玩家存档。

两方案使用**相同原文、相同模型摘要、相同8类问题、相同DeepSeek Flash文本模型、相同52,000 UTF-8字节预算**。此预算不是tokens，也不把窗口填满。每组做16次回答请求，合计48次；另有对话生成和摘要请求，成功测量112次。初次启动遇到轮数格式不足，初始修复请求不在本次成功测量统计中。模型速度受服务负载影响，不能据一次实验承诺稳定加速。

基线：现有最近对白、不可变摘要、关键词原文检索和预算。原型：工作记忆、近期摘要、带回合来源的结构化人物记忆、全文事件检索、原始冷归档；中文字词片段与精确代码结合，没有新增向量服务。人物记忆只从本人观察记录抽取，不以导演摘要建立新事实。时间、物品、关系和目标仍使用程序保存的结构化状态。

## 结果

|指标|原系统|分层原型|
|---|---:|---:|
|原文复核后答对|24/24|23/24|
|人物权限泄漏|0/3|1/3|
|未知信息承认未知|3/3|3/3|
|平均上下文字节|36,552|17,403|
|回答请求输入tokens合计|246,976|120,036|
|回答请求耗时中位数|1.078秒|0.992秒|

分层原型平均字节下降约52%，回答输入tokens下降约51%。这不等于账单下降51%：压缩也有消耗，缓存命中与未命中价格不同，本次没有测量长期净费用。

初始字符串评分把“不是南门”“不在书店”误判为错误，逐例核对后予以纠正。JSON同时保留原始lexical_passed、复核passed、原文回答和指标，不隐藏初始结果。

## 具体失败

问题：只按许老师本人记忆回答，他知道取书确认码吗？

原型回答承认不知道，却随后输出了只告诉他人的具体确认码。程序分开了演员观察记录，但单次模型请求仍能看到导演检索，提示词约束没有保证任意秘密都不外泄。原系统在同组问题没有输出确认码。

因此减少检索冗余不代表权限控制更可靠；目前的硬检查主要针对姓名/身份等已登记事实，不能宣称所有任意自由文本秘密均有代码保障。

## 细节丢失与后续方向

本样本的约定、物品、拒绝、传闻纠正均可从原文恢复；但规模有限，不能证明超长篇、复杂多人关系和非线性时间都不会遗漏。后续应先建立按当前回应人物裁剪的生成视图与通用秘密来源验证，再扩大检索质量实验。需要继续测试表达歧义、记忆纠正、人物转述、兄弟分支和回溯后未来信息。

原型保留在实验目录，不加入运行技能、不修改现有摘要、不迁移任何存档。

复现资料：`memory-experiment-result.json`、`experiment_memory.py`、实验原型`layered_memory.py`，模型原始公开故事与隔离记录位于本地`memory-experiment/`。重跑需要自己的DeepSeek本地配置；没有随报告附带密钥。
